# 旧影修复档案馆

老照片修复成果的公开展示与家属记忆征集平台。工作人员上传修复前后两张照片，
著录年代、人物说明与来源；家属在照片页提交补充记忆，经后台审核后公开。

前台遵循档案展示的克制原则：纸本色底、衬线排版，照片与文字为绝对主角，
无轮播、无悬浮特效、无过度动画；唯一的交互是详情页「修复前 / 修复后」拖动对比。

## 技术栈

Node.js + Express + EJS 服务端渲染，SQLite（better-sqlite3）存储，
multer 接收上传，sharp 统一图片处理（仅缩放/转正/转 JPEG，不做自动美颜），
bcryptjs 口令哈希，express-session 管理登录。

## 运行

```bash
npm install        # 如依赖未安装
npm run seed       # 建库、写入默认账号与三张示例档案
npm start          # http://localhost:3000
```

重置数据库（删除后重新种子）：`npm run reset`

### 默认工作人员账号

- 用户名：`admin`
- 口令：`admin123`
- 登录地址：`/login`（生产使用请修改口令）

## 页面与流程

| 角色 | 能做什么 |
| --- | --- |
| 访客 | 浏览首页、按年代筛选档案、查看照片详情（拖动对比修复前后）、阅读已公开的家属记忆 |
| 家属 | 无需登录，在照片页提交记忆（称呼、关系、联系方式、内容）；提交后进入待审核，**联系方式仅用于核实，绝不公开** |
| 工作人员 | 登录工作台：上传/编辑/删除照片（标题、年代、拍摄地、人物、来源、档案记述、状态）、审核记忆（通过公开 / 不予公开） |

照片有三种状态：`published`（公开）、`draft`（草稿，前台不可见、仅登录预览）、`archived`（归档）。
档案编号自动生成，形如 `JY-2026-001`；年代文本（如「1937 年春」）会自动提取十年锚点用于筛选，
无法辨认者归入「年代待考」。

## 目录

```
server.js            入口
db.js                SQLite 建表
lib/                 上传处理、鉴权中间件、工具函数
routes/              index（公开） auth（登录） admin（后台）
views/               EJS 模板（partials / admin / memories）
public/css|js|uploads 样式、对比脚本、图片落盘目录
tools/seed.js        初始化与示例数据（含程序生成的样片）
data/                SQLite 与 session 密钥（已在 .gitignore）
```

## 设计说明

- 配色取自旧相纸与档案盒：纸色 `#f5f1e8`、墨色正文、印章红仅用于编号与极少量强调。
- 字体为 Noto Serif SC / 系统宋体回退，宽松行距，正文限制行宽。
- 列表用细边框卡纸框，不做悬停位移与投影变化。
- 上传图片长边统一压到 2000px、质量 88，保留修复细节的同时控制体积。
